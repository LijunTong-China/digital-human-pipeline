## 2. douyin-login-service（端口 3459）

### 2.1 架构

- **方案A**：Playwright 持久化浏览器 + 人工扫码 + 定时保活。
- `browser/manager.py`：`chromium.launch_persistent_context(user_data_dir=browser_data/douyin)` **有头模式**，单例 + asyncio.Lock；附加 `--disable-blink-features=AutomationControlled` 与隐藏 `navigator.webdriver` 的 init_script。Cookie/指纹落盘于 `browser_data/douyin/`，重启不丢。
- `agent/`：LangGraph StateGraph。节点：`check_login → open_login_page → wait_for_scan → keepalive → finish`；未登录按 action 分支；扫码失败可重开登录页一次（MAX_SCAN_RETRIES=1）。已编译为全局 `login_graph`。
- `services/douyin.py`：`check_login()`（以 sessionid/sessionid_ss Cookie 判定）、`open_login_page()`、`wait_for_login()`（轮询最长 300 秒）、`keepalive_touch()`（访问首页并滚动刷新会话）。
- `main.py` lifespan 内启动保活循环：每 30 分钟（`config.KEEPALIVE_INTERVAL_SECONDS=1800`）。

### 2.2 当前全部接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/quant/login_status_all` | 所有平台登录状态（当前仅 douyin） |
| GET | `/api/quant/login_status/{platform}` | 单平台登录状态 |
| POST | `/api/quant/open-login-tab/{platform}` | 打开扫码页并阻塞等待（最长5分钟） |
| POST | `/api/quant/keepalive/{platform}` | 手动保活 |
| GET | `/api/quant/cookies/{platform}` | 导出 Cookie |
| POST | `/api/quant/fetch/{platform}` | 登录态代抓页面 |
| POST | `/api/quant/search/{platform}` | 真人行为搜索（首页输入→回车） |
| POST | `/api/quant/video_detail/{platform}` | 拦截 `/aweme/detail` XHR |
| POST | `/api/quant/capture_video/{platform}` | L3 MSE 分段捕获（音/视频轨分文件、content-range 排序拼接、8倍速播放、字节稳定2轮判定完成） |
| POST | `/api/quant/xhr_capture/{platform}` | 通用 XHR 拦截（知乎搜索等） |
| GET | `/` (静态) | `static/index.html` 登录中心页 |
| GET | `/api/health` | 健康检查 |

**平台限制：所有接口硬编码仅支持 douyin，其余平台返回 404"尚未接入"。**

## 3. hotspot-monitor-service（端口 8000）

### 3.1 架构与数据表

- FastAPI 入口 `main.py`：挂载 `api/routes.py`（前缀 `config.API_PREFIX="/api/hotspot"`，router 自带 `/api/v1`，**实际全路径为 `/api/hotspot/api/v1/...`**）+ APScheduler。
- ORM：SQLAlchemy 2.x，连接 `config.DATABASE_URL`（docker 环境实际为 `cloneai:cloneai_pass@localhost:15433(原文如此,§4 记为 15432,未复查)/hotspot_monitor`）。
- 数据表（`models/database.py`）：
  - `creators` — 创作者
  - `creator_videos` — 视频（含 transcript_* 转写字段、stats_* 统计字段）
  - `topics` — 选题，含 `embedding VECTOR(1024)`（pgvector）
  - `zhihu_articles` — 知乎热点采集表（voteup/keyword/category/tag_status/is_selected，对应知乎采集实验）
  - `sync_tasks` — 同步任务记录（JSONB result）
- Alembic 迁移仅有模板代码（database.py:206 附近），**无 alembic 环境，实际用 create_tables 建表**。

### 3.2 接口清单（前缀 `/api/hotspot/api/v1`）

**创作者**：POST `/creators`；GET `/creators/{id}`；GET `/creators`（分页/过滤）；PUT、DELETE `/creators/{id}`（软删除）；GET `/creators/{id}/stats`；POST `/creators/{id}/sync`（创建同步任务记录）；GET `/creators/{id}/tasks`

**视频**：POST `/videos`；GET `/videos/{id}`；GET `/videos`（分页/排序）；PUT、DELETE `/videos/{id}`；GET/POST `/videos/{id}/stats`；POST `/videos/{id}/transcribe`

**选题**：POST `/topics`（⚠️ 该端点直接操作 ORM，绕过 service 层）；GET `/topics/{id}`；GET `/topics`；PUT、DELETE；GET `/topics/{id}/stats`；GET `/topics/hot`；GET `/topics/quality`；POST `/topics/{video_id}/extract`（LLM 提取）；POST `/topics/{video_id}/deduplicate`（向量去重）

**统计**：GET `/stats/overview`（创作者/视频/选题数 + 转写统计）

**根级**：`GET /api/health`、`GET /api/config`

### 3.3 核心链路（真实实现）

- `services/sync_service.py` — **核心**。`SyncService.sync_creator()`：登录态健康检查 → 抓主页视频列表 → video_detail XHR 补全 → 入库去重 → 新视频自动下载转写（L2a/L2b/L3 降级链）。已知近似：`published_at` 用同步时间代替（主页列表拿不到精确发布时间）。
- `crawlers/douyin_crawler.py` — 不对抗风控，**复用 3459 登录态浏览器**：`LoginServiceClient` 调 `/api/quant/fetch|search|cookies|video_detail|capture_video`；三级播放地址 fallback（share 直连 → 登录态抓 share 页 → 详情页 RENDER_DATA）；MSE 分段捕获。
- `services/transcribe_service.py` — OpenAI 兼容 `/v1/audio/transcriptions`（默认 SiliconFlow SenseVoiceSmall）；ffmpeg 先转 16k wav，失败回退原文件直传。
- `services/topic_service.py` — LLM 提取选题 JSON 入库 + 标题向量；去重调 VectorDedup。
- `dedup/vector_dedup.py` — OpenAI 兼容 embeddings（默认 SiliconFlow BAAI/bge-m3，1024维）+ numpy 余弦相似度，阈值 0.85；**未用 pgvector 索引，Python 全表扫描比对**。
- `llm/` — 单一 `LLMClient`（OpenAI 兼容协议），`extract_topics()`/`summarize_text`/`generate_content`；`factory.py` 只是单例 getter，厂商由 config 的 BASE_URL+MODEL 决定（默认 DeepSeek deepseek-chat）。README 描述的"多提供商 DeepSeek/通义/GPT-4 类文件"实际不存在。
- `scheduler.py` — APScheduler BackgroundScheduler，5 个任务：每小时同步活跃创作者、每天 00:00 全量同步、每 30 分钟转写队列、每 1 小时选题提取、每 2 小时选题去重。

### 3.4 尚未实现 / 占位部分

## 7. 与原系统的关系（参考背景）

- `douyin-login-service` 的接口路径（`/api/quant/*`）刻意对齐原系统接口规范。
