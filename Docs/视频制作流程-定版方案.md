# 视频制作流程-定版方案(形象 IP + GPU 集中处理)

> 2026-09-27 定稿。固定五步流程,本文档是该流程的落地设计。
> 【2026-10-02 标识·历史文档】这是 **09-27 时点的旧定版,已被现行方案取代**,保留作演进记录。后续修正:步骤1 形象改为即梦白底图(白色键控,Kolors 因构图问题淘汰);步骤3 的 demo7 链路废弃,现为 `studio/content.py` LLM 动态演播稿 + MinerU 解析 PDF;步骤5 中 EchoMimicV2 已于 09-30 判死刑删除(整帧扩散脸部必崩),定版引擎为 EchoMimicV3-Flash;MuseTalk 相关内容全部作废。现行流程见 `studio/README.md`。
> 原则:全链路无人工环节;效果优先;商业 API 与租用 GPU(AutoDL 4090)结合。〔原则仍为现行原则〕

## 一、固定流程(五步)

```
步骤1  生成形象(一次性,沉淀为固定 IP 形象,后续所有视频复用)
步骤2  生成 PPT(NotebookLM 演示文稿,已有自动化链路)
步骤3  PPT → 视频(逐页图 + VL 讲解词 + TTS 配音 + 翻页/字幕,即 demo7 链路)
步骤4  视频叠加形象 + 声音替换(声纹克隆:以录入的声音为参考,替换 TTS 音色)
步骤5  形象动作驱动(对口型:张嘴/闭嘴/表情随语音;半身姿态动作)
```

## 二、各步骤技术选型

### 步骤1:形象生成 —— SiliconFlow Kolors(商业 API)〔历史:形象定为即梦白底图 assets/形象_white.png+白色键控,无 character/ 目录〕
- 模型:`Kwai-Kolors/Kolors`(SiliconFlow,约 ¥0.1/张),本机直接调 API。
- 产出:固定 prompt + 固定 seed 生成**卡通讲解人半身立绘**:正脸、闭嘴微笑、
  双手自然下垂、纯绿背景(#00FF00,便于后续抠像)、1024x1024。
- 沉淀:`assets/character/char.png`(定版形象)+ `char_prompt.json`
  (记录 prompt/seed/negative,保证以后重新生成一致或生成同 IP 新姿态)。
- 生成一次、本地缓存,**后续所有视频零成本复用**;不满意就改 prompt 重抽,定版后锁定。
- 升级路径:Kolors 效果不满意 → 换即梦 AI(火山引擎)文生图 API,接口封装不变。

### 步骤2:生成 PPT —— NotebookLM 自动化(已有)
- 专用浏览器 profile + MCP 接管业务页,自动产出 `demo/input/nb_slides.pdf`(已有链路,不变)〔历史:现行 studio/assets/slides.pdf,nb_auto.py 全自动+骨架提示词,'不变'不成立〕。

### 步骤3:PPT → 视频 —— demo7 链路(已有,微调)
- PyMuPDF 逐页转图 → Qwen3-VL 逐页写讲解词 → TTS 逐页配音 → 页时长对齐翻页
  → 背景(模糊铺满)+ 幻灯片居中 + 页级字幕。
- 本步骤已实现(demo/demo7_slides.py),仅保留:幻灯片底边锚 y=1300、字幕贴其下方。

### 步骤4:声音替换(声纹克隆)+ 叠加 —— AutoDL 4090〔历史:现行④一步到位(benjamin 本地 TTS 或服务器 clone),无'先 TTS 再替换'两段式;参考音路径=assets/voice_ref.wav〕
- **声纹克隆:CosyVoice2(部署在 4090)**
  - 录入一段 ≥10s 的本人声音作为参考音频(一次性上传,沉淀 `assets/character/ref_voice.wav`)。
  - 逐页讲解词文本 → zero-shot 克隆音色合成 → 替换原 TTS 配音,音色=本人声纹。
  - 备选:SiliconFlow 音色克隆 API(上传参考音频创建自定义音色,免 GPU),
    作为 4090 不可用时的降级路径,两者接口在 `voice_clone()` 内互换。
- **叠加:ffmpeg**
  - 形象视频绿幕抠像(chromakey)→ 缩小后叠在幻灯片右下角(步骤3 画面上)。
  - 音轨直接替换为克隆配音,翻页节奏按克隆配音时长重算。

### 步骤5:形象动作 —— AutoDL 4090
- **对口型(定版 2026-09-30):EchoMimicV3-Flash,双方案**
  - 方案③(脸部特写镜头):形象图先裁剪成脸占 2/3 的方形(crop 1300×1300)再生成,脸部最清晰
    张嘴/闭嘴/口型精确跟随语音,解决"不生动、不跟随"。
  - EchoMimicV2〔历史:09-30 判死刑并删除,不在现行方案;现行引擎=EMV3-Flash〕(已删除,不在现行方案,勿再考虑启用):音频驱动半身,自带手势动作,
    一次推理较慢(单页约 5~10 分钟),效果更生动。
  - 方案②(全身/全景镜头):整图直喂 768×768 生成,再 GFPGAN 逐帧人脸修复(0.5s/帧)
  - 整帧扩散,能带动表情/手势;长音频按 ~5s/段分段生成再拼接(129帧×768×768 是显存上限)
  - 环境与定版命令详见《GPU服务器执行命令记录.md》15 节;MuseTalk〔历史:09-30 已删,不在现行方案;现行引擎=EMV3-Flash〕已退役删除
    (均为 `lipsync(image, wav) -> mp4`);两者无演进关系,现行口型引擎直接用 EMV3-Flash,不存在先 MuseTalk 后 EMV3 的演进路径。

## 三、AutoDL 4090 环境(MCP SSH 全自动操作)

用 aiondadotcom/mcp-ssh 连接实例,一次性环境搭建 + 日常推理均由脚本完成:

1. **环境搭建(一次性,给一键脚本 `scripts/autodl_setup.sh`)〔历史:脚本未落地,MuseTalk 已删〕**
   - Miniconda 环境 → `pip install torch/cuda、musetalk 依赖`
   - 下载 MuseTalk 权重(沙冬儒生/HumanML 权重约 10GB,AutoDL 内网学术加速下载)
   - 上传 `ref_voice.wav`、`char.png`
2. **日常推理(脚本 `scripts/autodl_infer.sh`,幂等)〔历史:脚本未落地,MuseTalk 已删〕**
   - `scp` 上传 `jobs/<job_id>/`(立绘 + 逐页 wav)
   - 远程跑 MuseTalk → 逐页 mp4
   - `scp` 下载回 `demo/out/demo7/lipsync/`,失败重试一次
3. **计费与调度**:按量 4090 约 ¥2/时;集中处理——攒齐一整片(全部页)一次连接批量推理,
   推理完即关机,单条视频 GPU 成本 ≈ ¥0.5~1。

## 六、实施顺序(确认后执行)

1. `character_gen.py`:Kolors 生成形象 → 你看图定版(这是唯一需要你拍板的点)
2. AutoDL 开实例 → `autodl_setup.sh` 装环境(我通过 MCP SSH 全程操作)

5. 录入你的参考声音(≥10s 干音),接入 CosyVoice2 声纹克隆,替换配音
6. (~可选,已废弃)EchoMimicV2〔历史:09-30 判死刑并删除,不在现行方案;现行引擎=EMV3-Flash〕对比,决定动作档位

| 风险 | 对策 |
